# Decisions and open questions

## Current implementation decisions

- HashRouter supports static Pages without rewrites.
- Edition values and demo events live in dedicated config/data modules.
- INR pass is independently mandatory; base values and add-on prices are separate.
- The UI labels all payment, verification and data actions as demo-only.
- Supplied logos are referenced at natural proportions; prototype illustration is decorative.

## Organizer/faculty approval needed

- Final included event value cap: planning discussion mentions ₹400 or ₹450; demo uses ₹450 illustratively.
- Included event count: 3 or 4, and whether exactly that count or up to it.
- Official tagline, approved Parallax/ISTE marks and logo lockup.
- Convention dates, program hours, rooms and venue details.
- Final event list, individual/team formats, team sizes, eligibility, rules, capacity and each base/add-on price.
- Official ISTE email, social accounts, travel and accommodation content.
- Student verification policy, payment provider, confirmation email decision, cancellations/refunds and accessibility support.
- Final registration volume/capacity and team pass policy exceptions, if any.
