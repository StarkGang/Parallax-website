# Product overview

PARALLAX is a proposed two-day ISTE state student convention hosted at NSS College of Engineering, Palakkad. This repository is a static frontend demonstration for faculty and organizing committee review. It illustrates public convention information, a searchable event directory, pass policy, local event selection and participant/coordinator dashboard concepts.

No backend, account, eligibility verification, payment, registration persistence, email, ticketing or live operational schedule exists. Dates and several policy details remain unconfirmed. See [Business rules](BUSINESS_RULES.md) and [open decisions](DECISIONS_AND_OPEN_QUESTIONS.md).
