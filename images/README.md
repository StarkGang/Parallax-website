# Supplied visual assets

This root folder contains organizer-supplied Parallax, ISTE and NSSCE visual references. Keep original files intact and in their supplied locations. Add new originals here; use descriptive names such as `parallax-logo-primary.svg`, `iste-mark-transparent.png`, or `hero-abstract-01.webp`, and group them into `logos/`, `backgrounds/`, `elements/`, or `event-icons/` only when adding new materials (do not reorganize the supplied tree as part of routine edits).

Prefer SVG for approved logos and simple artwork, transparent PNG/WebP for cutouts, and optimized JPG/WebP for photographs. Include source, approval status, dimensions and intended use in `docs/IMAGE_ASSET_INVENTORY.md`. Never replace or modify an official logo without brand-owner approval. Preserve aspect ratio and use `object-fit: contain` for logos. Derived/optimized files belong in a separate clearly named project-owned directory; originals remain untouched.
